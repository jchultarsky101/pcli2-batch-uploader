## [Unreleased]

### Added

- CLI with `--manifest`, `--archive`, `--dry-run`, and `--verbose` options
- Excel manifest parser (reads `.xlsx` files via calamine)
- ZIP archive reader with nested path support
- Simulated pcli2 upload (placeholder for future integration)
- Structured logging via tracing
- Unit tests for all modules
- Integration tests for end-to-end CLI behavior
- cargo-dist CI configuration for cross-platform releases
- MIT license and standard open source files
